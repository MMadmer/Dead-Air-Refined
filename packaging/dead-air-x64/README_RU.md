# Dead Air 0.98b x64

Версия игры: **Dead Air 0.98b**

Версия x64-порта: **1.0.0**

Все файлы `Dead-Air-0.98b-x64-1.0.0-Setup*.bin` должны лежать рядом с
`Dead-Air-0.98b-x64-1.0.0-Setup.exe`. Запускается только EXE; BIN-файлы мастер
прочитает самостоятельно.

## Установка

1. Закрой Dead Air.
2. Запусти `Dead-Air-0.98b-x64-1.0.0-Setup.exe`.
3. Выбери тип установки.
4. Укажи папку игры или новую пустую папку.
5. Нажми «Установить».
6. После завершения запускай `xrEngine.exe` или созданный мастером ярлык.

PowerShell и JSGME для установки x64-движка не нужны.

## Обновление существующей x86-игры

Этот режим предназначен для уже установленной Dead Air 0.98b или Dead Air
Revolution II.

Мастер:

- проверяет наличие `xrEngine.exe`, `fsgame.ltx` и базового XDB;
- сохраняет заменяемые x86-файлы в `.dead-air-x64\backup-x86`;
- устанавливает x64-движок в ту же папку;
- не изменяет `database`, `gamedata`, `appdata`, сохранения, `MODS`, JSGME и
  подключённые аддоны.

## Чистая самостоятельная установка

Этот режим устанавливает в новую или пустую папку:

- чистые базовые архивы Dead Air 0.98b;
- полный x64-движок;
- необходимые системные библиотеки;
- ярлыки запуска и удаления.

Dead Air Revolution II, Inventory Sort, Oxygen HUD, другие моды и пользовательские
сохранения в чистую версию не включаются.

## Удаление

Закрой игру и запусти из её папки:

```text
Uninstall Dead Air x64.exe
```

Удаление также доступно через список установленных приложений Windows.

Для обновлённой x86-игры деинсталлятор удалит x64-файлы и восстановит исходный
x86-движок. Для самостоятельной версии он удалит установленные файлы игры.
Созданные после установки `appdata`, настройки и сохранения не удаляются.

## Версионирование

Версия оригинальной игры всегда остаётся `0.98b`. Отдельно меняется версия
x64-порта по Semantic Versioning:

```text
Dead Air 0.98b x64 Port 1.0.0
Dead Air 0.98b x64 Port 1.0.1
Dead Air 0.98b x64 Port 1.1.0
Dead Air 0.98b x64 Port 2.0.0
```

- `PATCH`, например `1.0.1`, — исправления без изменения совместимости.
- `MINOR`, например `1.1.0`, — новые обратно совместимые возможности.
- `MAJOR`, например `2.0.0`, — несовместимые изменения API модов, формата
  сохранений или требований к контенту.

Рекомендуемое имя архива:

```text
Dead-Air-0.98b-x64-1.0.0.zip
```

## Сборка установщика

После сборки Release x64 выполни:

```powershell
cd "D:\Games\Dead Air\DeadAir-x64"
pwsh -NoProfile -ExecutionPolicy Bypass -File `
  ".\tools\package\build_dead_air_x64_installer.ps1"
```

Скрипт проверяет payload, локально устанавливает подписанный компилятор Inno
Setup при его отсутствии, собирает GUI-установщик, создаёт контрольные суммы и
упаковывает дистрибутив в `artifacts`.
