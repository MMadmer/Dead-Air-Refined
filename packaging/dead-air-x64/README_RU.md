# Dead Air 0.98b x64

Версия игры: **Dead Air 0.98b**

Версия x64-порта: **1.0.0**

Данный выпуск переносит движок Dead Air 0.98b на 64-разрядную архитектуру. Порт
сохраняет стандартную структуру каталогов игры, порядок загрузки XDB-архивов,
папку `gamedata`, сохранения и обычные способы установки аддонов.

## Состав дистрибутива

Все файлы `Dead-Air-0.98b-x64-1.0.0-Setup*.bin` должны находиться в одном
каталоге с `Dead-Air-0.98b-x64-1.0.0-Setup.exe`. Для начала установки необходимо
запустить только EXE-файл. BIN-файлы будут подключены установщиком автоматически.

Файл `SHA256SUMS.txt` содержит контрольные суммы всех файлов дистрибутива.

## Требования

- 64-разрядная версия Windows.
- Для режима обновления — установленная Dead Air 0.98b или Dead Air Revolution II.
- Свободное место, достаточное для установки и, при выборе соответствующей
  опции, резервной копии заменяемых файлов движка.

Перед установкой необходимо закрыть игру и связанные с ней программы.

## Установка

1. Запустите `Dead-Air-0.98b-x64-1.0.0-Setup.exe`.
2. Выберите требуемый тип установки.
3. Укажите корневой каталог существующей игры либо новый каталог для
   самостоятельной установки.
4. Проверьте выбранные параметры и нажмите «Установить».
5. После завершения установки запустите игру с помощью `xrEngine.exe` или
   созданного установщиком ярлыка.

PowerShell, JSGME и другие менеджеры модификаций для установки x64-порта не
требуются.

## Режим отображения

В разделе настроек видео вместо прежнего переключателя полноэкранного режима
доступен список «Режим отображения»:

- «Оконный» — обычное окно с системной рамкой, заголовком и кнопками управления;
- «Полноэкранный в окне» — окно без рамки, занимающее весь выбранный монитор;
- «Полноэкранный» — эксклюзивный полноэкранный режим.

Для нового профиля по умолчанию используется полноэкранный режим в окне и
разрешение рабочего стола. Существующие пользовательские настройки не
сбрасываются. В полноэкранном режиме в окне физический размер окна всегда
соответствует размеру монитора; выбранное разрешение определяет внутреннее
разрешение рендеринга.

## Обновление существующей установки

Режим предназначен как для оригинальной Dead Air 0.98b или Dead Air Revolution
II, так и для любой уже установленной версии x64-патча. Допускаются повторная
установка той же версии, обновление и переход на более раннюю версию патча.
Необходимо выбрать корневой каталог игры, содержащий `xrEngine.exe`,
`fsgame.ltx` и каталог `database`.

Установщик выполняет следующие операции:

- проверяет выбранную установку;
- при включённой опции резервного копирования создаёт новый независимый снимок
  текущей версии в `.dead-air-x64\backups`;
- устанавливает x64-движок в тот же каталог;
- сохраняет существующие `database`, `gamedata`, `appdata`, сохранения, `MODS`,
  настройки JSGME и установленные контентные аддоны.

Опция создания резервной копии включена по умолчанию. При её отключении
установщик заменит текущие файлы без создания нового снимка. Ранее созданные
резервные копии не изменяются и остаются доступными для отката.

## Чистая самостоятельная установка

Режим предназначен для установки отдельного экземпляра игры. Необходимо выбрать
новый или пустой каталог.

Установщик добавляет:

- базовые архивы чистой Dead Air 0.98b;
- полный комплект файлов x64-движка;
- необходимые системные библиотеки;
- ярлыки запуска и удаления.

Dead Air Revolution II, сторонние аддоны, модификации интерфейса и
пользовательские сохранения в самостоятельную установку не входят.

## Совместимость с модификациями

Скриптовые и контентные аддоны, использующие стандартные каталоги `gamedata`,
`database` или `MODS`, устанавливаются в прежнем порядке. Сохраняется
совместимость с обычными менеджерами модификаций, включая JSGME.

Базовые изменения меню видео поставляются в отдельном архиве
`database\xtra_dead_air_x64.xdb0`. Установщик не размещает заменяемые файлы в
`gamedata`, поэтому стандартный порядок переопределения файлов аддонами
сохраняется.

32-разрядные нативные плагины и аддоны, заменяющие `xrEngine.exe` или DLL-файлы
движка, несовместимы с 64-разрядным процессом. Для таких компонентов требуется
отдельная x64-сборка.

## Удаление

Перед удалением необходимо закрыть игру. Запустите файл
`Uninstall Dead Air x64.exe` из корневого каталога установленной игры либо
воспользуйтесь разделом установленных приложений Windows.

Деинсталлятор предлагает два режима:

- полное удаление x64-патча; отдельная опция позволяет также удалить все
  резервные копии из служебного каталога игры;
- откат файлов игры до выбранной резервной копии. Папка снимка выбирается
  вручную. После отката выбранная резервная копия сохраняется, а
  деинсталлятор остаётся доступен для дальнейшего обслуживания версии.

Для отката используется содержимое самого выбранного снимка. Совпадение версии
или установщика, которым он был создан, не требуется. Перед восстановлением
проверяется наличие всех заявленных в снимке файлов.

Каталог `appdata`, пользовательские настройки и сохранения, созданные после
установки, автоматически не удаляются.

## Версионирование

Версия исходной игры сохраняется как `0.98b`. Версия x64-порта указывается
отдельно в формате Semantic Versioning:

- `PATCH` (`1.0.1`) — исправления без изменения совместимости;
- `MINOR` (`1.1.0`) — новые обратно совместимые возможности;
- `MAJOR` (`2.0.0`) — несовместимые изменения API, формата сохранений или
  требований к контенту.

Полное обозначение текущего выпуска: **Dead Air 0.98b x64 Port 1.0.0**.
