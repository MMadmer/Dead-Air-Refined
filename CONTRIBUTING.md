# Contributing to Dead Air: Refined

Bug reports and proposals belong in the
[Dead Air: Refined issue tracker](https://github.com/MMadmer/Dead-Air-Refined/issues).

Before changing code, read [`PROJECT_RULES.md`](PROJECT_RULES.md). It defines
the compatibility boundary, supported build pipeline, coding rules, validation
requirements, commit policy, and release process for this project.

Discuss changes that affect gameplay, saves, Lua/API compatibility, rendering
quality, packaging, or the update protocol before implementation.
