# Капитальная оптимизация рендера Dead Air x64

## Итог прохода

- Крупные принятые оптимизации: 15.
- Обычные принятые оптимизации: 19.
- Дополнительные оптимизации после повторного анализа: 7.
- Отклонённые эксперименты: 4.
- Release x64: сборка завершена с 0 ошибок.
- Скрытый runtime smoke-test: сохранение загружено до `actor_restored`, рендер
  запущен, процесс отвечает, новых fatal/assert/access violation нет.
- Снижение графических настроек, дальности, плотности, разрешения эффектов и
  качества шейдеров не применялось.

## Крупные принятые оптимизации

### B01. Реальный временной skip HOM-треугольников

`CHOM::Render_DB` теперь исключает отложенные треугольники из обработки.
Раньше результат фильтрации фактически игнорировался. Интервал skip считается
локальным детерминированным хешем и больше не расходует глобальный игровой RNG.

### B02. Иерархический reject HOM

Верхние уровни пирамиды глубины используются для безопасного раннего
отклонения. Неопределённые случаи по-прежнему проходят точную проверку level 0.

### B03. SIMD-построение пирамиды глубины HOM

Редукция 2x2 переведена на SSE2 с тем же signed max. Финальный изолированный
тест: результат совпадает, ускорение `1,691x`.

### B04. Сохранение пулов scene graph между кадрами

Покадровый reset очищает содержимое, но сохраняет выделенные узлы и capacity.
Повторяющиеся освобождения и аллокации дерева больше не выполняются.

### B05. Ленивое обслуживание D3D11-контекстов

Frame begin/end обслуживает immediate context один раз. Deferred context
сбрасывается в точке реального выделения/завершения, а не каждый кадр.

### B06. Подавление лишних обновлений constant buffer

Добавлены точные dirty-range, committed shadow и очередь изменённых буферов.
Идентичные значения не приводят к повторному `Map(WRITE_DISCARD)` и bind.
Состояние безопасно отменяется при invalidate.

Изолированный тест dirty-path:

- повтор значения раз в 4 обновления: `1,233x`;
- раз в 16: `1,567x`;
- раз в 64: `1,868x`.

Чисто CPU-сценарий, где каждое значение всегда различается, оказался медленнее
из-за сравнения памяти. Для него добавлен флаг known-different, исключающий
повторные сравнения уже грязного буфера.

### B07. Кэш применения sampler state

Передаётся только занятый диапазон слотов, корректно очищаются старые хвосты.
Для каждого context/stage хранится последнее привязанное состояние, поэтому
повторный driver call пропускается.

### B08. Горячий путь skeletal animation

Убран повторный modulo для каждого канала, добавлены channel-mask и
single-channel fast path. Additive base key вычисляется только для реально
аддитивных каналов. Горячие helpers принудительно встраиваются.

### B09. Сортировка spatial-объектов по готовому ключу

Квадрат расстояния вычисляется один раз и хранится рядом с объектом. Компаратор
больше не повторяет векторную математику. Финальный изолированный тест: точный
порядок, ускорение `1,912x`.

### B10. SIMD `Fmatrix::mul_43`

Матричное умножение переведено на SSE без изменения результата.
Миллион случайных случаев совпал побитно; ускорение `2,058x`.

### B11. Быстрое преобразование skeletal AABB

Вместо восьми преобразований углов используются центр и extent. Миллион
случайных случаев совпал в пределах `0,0002`; ускорение `2,329x`.

### B12. Упаковка и сортировка источников света

Невидимые shadow lights компактируются линейно. Размеры теней сортируются один
раз, оставшийся список сохраняет порядок без повторных erase/sort.

### B13. Видимость деталей

Исправлена маска frustum: старые лишние биты не позволяли получить
`fcvFully` и заставляли проверять каждый внутренний slot. Очищаются только
ранее использованные списки; draw проходит только по видимым model ID.
Квадраты радиусов и vertex/index offsets подготовлены заранее.

### B14. Кэш неизменного D3D backend state

Добавлены fast path для viewport, scissor, render state, SRV, texture list,
input layout, color-write mask и размеров DSV. Повторные вызовы драйвера и
запросы descriptor исключены при неизменном состоянии.

### B15. HDAO dispatch и очистка ресурсов

Фаза не запускается при выключенном SSAO. Размер dispatch считается точным
целочисленным ceil, используется текущий context ID, ресурсы очищаются через
общий backend cache.

## Обычные принятые оптимизации

1. Bit-scan свободного deferred context через `std::countr_zero`.
2. Bit-scan только активных плоскостей frustum.
3. Guard от сортировки массивов из 0 или 1 элемента.
4. Строгий comparator проходов вместо `>=`.
5. Базовая вершина HOM fan трансформируется один раз.
6. Неизменные HOM viewport matrices стали статическими.
7. Квадраты радиусов detail models кэшируются.
8. Очищаются только реально использованные detail visibility lists.
9. Distance/fade reject деталей выполняется до HOM.
10. Убраны повторные `GetSpatialData` одного объекта.
11. Сортировка light lists пропускается для 0/1 элемента.
12. Неизменившийся render state не применяется повторно.
13. Текущий SRV context кэшируется.
14. Размеры DSV не запрашиваются повторно.
15. Detail vertex/index offsets вычисляются заранее.
16. Повторная неизменная texture list получает fast path.
17. Color write изменяет только реально отличающиеся слоты.
18. Из detail vertex dump убрана неиспользуемая environment-математика.
19. Renderer HOM больше не сдвигает глобальный игровой RNG.

Изолированный тест обхода активных плоскостей frustum: 500 000 случайных
случаев совпали, ускорение `1,249x`.

Дополнительный тест SIMD-преобразования HOM box: миллион случаев совпал,
ускорение `2,082x`.

## Дополнительный анализ после минимального объёма

После выполнения первых 5 крупных и 10 обычных пунктов дополнительно приняты:

1. активная frustum mask через bit-scan;
2. список только видимых detail model ID;
3. exact dirty ranges constant buffer;
4. безопасная отмена pending constant buffers при invalidate;
5. HDAO cleanup через backend cache;
6. DSV dimension cache;
7. независимый от игрового RNG HOM skip.

## Отклонённые эксперименты

1. Reciprocal вместо делений в `i_scan`/`i_section`: отклонено из-за риска
   изменения растеризации и картинки на граничных значениях.
2. Хранение ссылок вместо копий matrix items: отклонено без доказанного времени
   жизни матриц.
3. Полная замена scene graph на плоскую структуру: отклонено из-за высокого
   риска изменения порядка рендера.
4. Изменение GPU query wait policy: отклонено без воспроизводимого stall,
   который оправдывал бы изменение latency.

## Проверка

- Все математические A/B-тесты сравнивают результат старого и нового пути.
- Финальная Release x64 сборка: 0 ошибок, 13 прежних предупреждений
  LuaJIT/LIBCMT/lzo PDB.
- Финальные 42 PE-файла вручную установлены в корень игры.
- Скрытый runtime smoke-test загрузил `async_benchmark_1`; после
  `actor_restored` процесс продолжал рендерить и отвечать.
- В runtime-логе нет новых fatal, assert и access violation.
- Системный post-change WPR-профиль не снимался: после перезагрузки ноутбука
  Windows снова требует повышенного права `Profile system performance`.
  Поэтому в документе не заявляется неподтверждённый общий прирост FPS.
